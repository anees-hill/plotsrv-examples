# Source fixtures

The HTML, JSON, YAML, image, and three-row `table-small.csv` fixtures are retained
for readable format examples. They are inputs, not runtime state.

Larger CSV, text, and log inputs are generated by `plotsrv_examples.fixtures` into
an ignored owned run. From the repository root:

```bash
export PLOTSRV_FIXTURE_DIR="$(uv run --no-sync python -B -m plotsrv_examples fixtures-create)"
bash src/launchers/python-objs/00-python-objs.sh
# After stopping all readers and writers:
uv run --no-sync python -B -m plotsrv_examples workspace-clean "$PLOTSRV_FIXTURE_DIR"
```

The environment variable selects generated input paths for legacy launchers;
it does not authorize cleanup of arbitrary directories.

Defaults: seed 17, 100,000 large-table data rows, 20 columns, and 4,096 text/log
lines. `--seed`, `--rows`, and `--lines` are explicit; accepted ranges are
0–4,294,967,295, 1–100,000, and 1–10,000 respectively. The small/medium generated
tables always have 100/1,000 data rows. Maximum output is below 16 MiB and is
written incrementally. The legacy name `6000_20.csv` is retained for compatibility;
its historical file actually contained about 100,000 rows.

`fixtures.json` records generator format version, parameters, byte lengths, and
SHA-256 hashes. Data uses fixed integer arithmetic and UTF-8/LF, with no network,
wall clock, or random-library dependency. Equal parameters produce equal data and
manifest bytes; ownership markers intentionally differ between runs. Log lines
are labelled synthetic fixture requests and are not captured server output.

Historical generated files were removed from Git's index and are now ignored.
Existing local copies remain untouched; fresh checkouts use the generator.
